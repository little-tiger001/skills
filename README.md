# Personal Agent Skills

A collection of reusable skills for AI coding agents.

## Skills

- `mineru`: Read and parse local documents through the official MinerU API. It checks the current workspace `.mineru/` cache before parsing a PDF.

## Installation

Clone this repository into the agent's skills directory, or copy/link an individual skill into the directory supported by your agent.

Never commit real API tokens. Copy a skill's `.env.example` to `.env` and fill in local credentials.
