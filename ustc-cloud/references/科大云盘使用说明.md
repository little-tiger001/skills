# 科大云盘使用说明

> 依据官方帮助 <https://pan.ustc.edu.cn/doc/private/> 整理（原文含界面截图，本文只保留要点，截图请见原文）。
> 整理时间：2026-10-14。

科大云盘是学校的 Seafile 网盘服务（<https://pan.ustc.edu.cn>）。文档里的「资料库」对应 Seafile 的 library —— 资料库是同步与权限的最小单位，**忽略规则、解除同步等操作都以资料库为范围**。

---

## 一、网页版使用

| 功能 | 说明 |
|---|---|
| 创建资料库 | 点「新建资料库」命名即可；支持重命名、删除 |
| 新建文件/文件夹 | 进入资料库后可上传文件（含整个文件夹），也可在线新建文件夹及 markdown、Word、Excel、PowerPoint 文件（Office 三件套由部署在校内网的 OnlyOffice 支持） |
| 管理文件/文件夹 | 支持移动、复制、删除、重命名等 |
| 预览 | 支持视频等在线预览 |
| 分享 | 可生成分享链接 |
| 历史版本 | 可查看/恢复文件的历史版本 |
| 标签 | 可给文件打标签 |

> 官方提示：请勿分享任何违反相关法律法规的内容，包括但不限于未授权的软件、影像、音频、字体等。

## 二、桌面客户端使用

- 安装完成后，客户端会自动用系统默认浏览器打开 web 端登录页；在网页端完成登录后，客户端里才能看到完整的资料库列表。
- 已知冲突：**当前版本的科大云盘客户端与 Seafile 社区版客户端同时安装会冲突**（官方称下一版本修复）。若同时使用 Seafile 网盘，暂缓使用科大云盘。

### 1. 同步云端资料库到本地

在客户端资料库列表里右键某个资料库 → 选「同步该资料库」，即把远程资料库同步到本地。

### 2. 把本地文件/文件夹加到云端

- **目标资料库已同步到本地**：直接在同步路径里新增/删除文件或文件夹，会自动同步到云端。
- **把一个本地文件夹变成新资料库**：客户端里选「同步本地文件夹到云端」→ 弹框填「路径」（要同步的本地文件夹）与「名字」（服务器上的资料库名）→ 确定后服务器新建资料库并开始同步，之后在「我的资料库」列表可见。

### 3. 解除同步与重新同步

不想再让某资料库和本地文件夹同步时，对资料库执行「解除同步」：此后本地改动不再上传、云端改动不再下载（云端文件本身保留）。想恢复时用「和已有文件夹同步」功能重新绑定。

### 4. 只读同步

只读的资料库或文件夹，客户端里显示为灰色禁用图标。

### 5. 文件冲突处理

多人同时编辑同一文件时，先编辑完成的版本保存到服务器，另一个版本被重命名为「冲突文件」，名称以作者姓名和当前时间结尾，例如：

```
test.txt(SFConflict 张三 2017-12-25-11-30-28)
```

### 6. 收藏与文件活动

- 客户端点**星形图标**：查看收藏的文件/文件夹。
- 客户端点**钟表图标**：查看文件/文件夹的活动历史。

### 7. 其他设置

- **代理**：支持 HTTP 代理、SOCKS5 代理、系统代理三种。
- **账号切换**：点客户端上方头像 → 登出，即可换账号登录。
- **客户端设置**：右键系统通知区域的「科大云盘」图标 → 「设置」。

## 三、忽略本地文件/文件夹的自动同步

不想把资料库里的某些内容同步到服务器时，用忽略列表实现。

### 做法

在**资料库的根目录**创建一个名为 `seafile-ignore.txt` 的文本文件（不要用 Word 之类的富文本编辑器），文件的每一行对应一个模式（pattern）。

### 规则要点

- `#` 开头的行是注释，空行不匹配任何文件。
- 支持通配符 `*` 和 `?`。`*` 会**递归**匹配目录下的所有路径，例如 `test-star2/*.html` 同时匹配 `test-star2/a.html` 和 `test-star2/templates/b.html`；`test-qu1/?.html` 只匹配单字符文件名。
- 模式以 `/` 结尾时**只匹配目录**（连同目录下所有内容），例如 `test-dir/`；不以 `/` 或通配符结尾时**只匹配文件**，例如 `test-file` 不会匹配同名目录。
- 示例（对应原文截图）：

  ```
  # a regular file
  test-file
  # a dir
  test-dir/
  # wildcard *
  test-star1/
  test-star2/*.html
  # wildcard ?
  test-qu1/?.html
  test-qu2/?/
  ```

### 客户端实现细节（读源码核实，2026-10-14）

- 每行 pattern 会被拼成「资料库绝对路径 + `/` + pattern」（以 `/` 结尾的行会再补一个 `*`），再用 GLib `g_pattern_match_string` 整体匹配。所以 `*` 可跨 `/`，`*.zip` 实际匹配任意深度的 zip；`.mineru/` 只匹配库根下的 `.mineru`，要任意深度需写 `*/.mineru/`。
- 每次提交前重新读取该文件，改完不需要重启客户端。

### 生效范围与限制（重要）

1. **只作用于客户端，不影响服务器行为。** 你仍然可以在网页端创建被客户端忽略的文件；这种情况下该文件会被同步到客户端，但客户端对它的后续修改不会回传服务器；若服务器端后续又改了这个文件，而客户端也改过，就会生成冲突文件。
2. **只忽略「还没有被同步」的文件。** 已经被同步的文件，事后加进 `seafile-ignore.txt` 只会忽略后续更改，**已经上传的版本不会受影响、也不会从服务器删除**。想真正从云端删除，需要在网页端或其它客户端删除。
3. ⚠️ **删除方向要当心**：忽略规则不保护下行。`seaf_repo_fetch_and_checkout()` 加载了 ignore 列表却没有使用它，判断是否跳过本地删除的 `should_ignore_on_checkout()`（`lib/utils.c`）只看 Windows 非法路径。因此**在云端删除一个"本地已忽略但仍留在索引里"的文件，客户端会把本地副本一起删掉**。要腾云盘空间，先把要保留的文件复制到资料库之外。
4. `seafile-ignore.txt` 必须放在资料库根目录，**放在子目录无效**。
5. 忽略文件本身默认也会同步到服务器（其它客户端会收到它）；如果不想这样，在文件里加一行 `seafile-ignore.txt`。
6. 如果整个子目录都不需要下载/同步，也可以考虑客户端的「选择性同步」取消勾选该子目录；整库层面的还有「解除同步」。

## 四、WebDAV 与 API（实测）

| 项 | 结论 |
|---|---|
| WebDAV 端点 | `https://pan.ustc.edu.cn/seafile/seafdav/` |
| 认证 | HTTP Basic：用户名 + 密码。用户名用带 `@auth.local` 后缀的形式（如 `2202315921@auth.local`）。`PROPFIND /seafile/seafdav/` 无凭据返回 `401` + `WWW-Authenticate: Basic realm="Seafile Authentication"`；用假凭据返回 `401 Access not authorized`；**用本机凭据实测返回 `207`，列出 6 个资料库：笔记 / 大三上 / 大三下 / zotero / 大四上 / Backup** |
| 路径结构 | 顶层即各资料库，库内路径接在资料库名之后：`<资料库名>/<子路径>`（已实测：`大四上/` 下 7 个目录 + `学期计划.md` + `seafile-ignore.txt`） |
| 无效端点 | `/seafile/dav/`、`/seafile/seafdav`（无尾斜杠）、`/dav/` 均不可用（404 / 405） |
| API token | **不可用**：该部署没有用户可自助获取的 API token。`POST /seafile/api2/auth-token/` 只认账号密码（用不存在的用户名探测返回 `400 Unable to login with provided credentials.`）；客户端 `repo.db` 里存的 40 位 token 是同步协议专用，用于 `/api2/` 一律 `401 Invalid token` |

常用命令：

```bash
BASE=https://pan.ustc.edu.cn/seafile/seafdav/
curl -u "$USER:$PASS" -X PROPFIND -H "Depth: 1" "$BASE"        # 列资料库
curl -u "$USER:$PASS" -X PROPFIND -H "Depth: 1" "$BASE/大四上/" # 列库内目录
curl -u "$USER:$PASS" -o out.md "$BASE/大四上/学期计划.md"       # 下载
curl -u "$USER:$PASS" -T ./local.txt "$BASE/大四上/local.txt"    # 上传
curl -u "$USER:$PASS" -X DELETE "$BASE/大四上/local.txt"         # 删除
curl -u "$USER:$PASS" -X MKCOL "$BASE/大四上/新目录/"             # 建目录
```

Windows 映射盘符（需启动 `WebClient` 服务）：`net use Z: https://pan.ustc.edu.cn/seafile/seafdav/ /user:<用户名> *`。
