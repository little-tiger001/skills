# 设计参考（从 SKILL.md 拆出，按需读）

## 先问风格

动手前确认视觉风格，它决定配色、版面密度和用图力度：

| 风格 | 特征 | 用图策略 |
|------|------|----------|
| **极简** | 干净、留白为主、靠字体撑场面 | 极少用图，靠形状/图标/留白；全篇 1–2 张 |
| **科技/未来** | 深色背景、几何装饰、现代 | 封面/章节页用生成的抽象背景；内容页用形状与图标 |
| **商务/企业** | 专业、结构化、可信 | 关键页用图片，约占 30–40% 页；其余用干净版式加图标 |
| **创意/张扬** | 醒目、表现力强、图像重 | 60–80% 页用满幅图或插画 |
| **学术/技术** | 数据导向、结构清晰、克制 | 只放图表和示意，装饰性图片只会干扰 |

用户没说时按场景推断（课题汇报 → 学术，产品发布 → 科技）。确实不清楚就问一句。

## 配色

选一个**由内容决定**的配色：一个主色占 60–70% 视觉重量，1–2 个辅助色，一个锐利强调色。深色用于封面与结尾、浅色用于内容页（"三明治"），或全篇深色走高级感。

| 主题 | 主色 | 辅助 | 强调 |
|------|------|------|------|
| Midnight Executive | `1E2761` | `CADCFC` | `FFFFFF` |
| Forest & Moss | `2C5F2D` | `97BC62` | `F5F5F5` |
| Coral Energy | `F96167` | `F9E795` | `2F3C7E` |
| Warm Terracotta | `B85042` | `E7E8D1` | `A7BEAE` |
| Ocean Gradient | `065A82` | `1C7293` | `21295C` |
| Charcoal Minimal | `36454F` | `F2F2F2` | `212121` |
| Teal Trust | `028090` | `00A896` | `02C39A` |
| Berry & Cream | `6D2E46` | `A26769` | `ECE2D0` |
| Sage Calm | `84B59F` | `69A297` | `50808E` |
| Cherry Bold | `990011` | `FCF6F5` | `2F3C7E` |

海洋/地学类课题可考虑 Ocean Gradient、Teal Trust；学校汇报注意与校徽色系是否冲突。

## 字体与字号

| 标题字体 | 正文字体 |
|----------|----------|
| Georgia | Calibri |
| Arial Black | Arial |
| Calibri | Calibri Light |
| Cambria | Calibri |
| Trebuchet MS | Calibri |
| 微软雅黑 / 思源黑体（中文场景） | 微软雅黑 |

| 元素 | 字号 |
|------|------|
| 页标题 | 36–44pt 粗体 |
| 小节标题 | 20–24pt 粗体 |
| 正文 | 14–16pt |
| 图注/脚注 | 10–12pt 弱化 |

中文标题常需比英文略小；设备缺字体时会被替换，关键交付件必须真实渲染复核。

## 版面

- 边距至少 0.5"，内容块间距 0.3–0.5" 并保持一致。
- 每页都要有一个视觉元素：图、图表、图标或形状；纯标题+项目符号的页最容易被忘掉。
- 版面轮换：两栏（左文右图）、图标+文字行、2×2 / 2×3 网格、半幅出血图叠加文字。
- 数据：大数字卡片（60–72pt 数字 + 小标签）、对比栏（前/后、优/劣）、时间线或流程箭头。
- 挑**一个**视觉母题贯穿全篇（图标底色圆圈、单侧粗边、圆角图框），不要每页换花样。

## 不要做

- 不要每页同一版式，也不要一页塞满。
- 正文不要居中（标题可以）。
- 标题与正文的字号差距要够（36pt+ vs 14–16pt）。
- 不要默认蓝；配色要针对本次主题。
- 不要间距随意（统一 0.3" 或 0.5"）。
- 不要只有一页精心设计、其余留白。
- 不要低对比（浅字浅底、深图标深底）。
- **不要给标题加装饰下划线**——这是 AI 生成幻灯片的典型特征，用留白或底色区分。
- 文本框有内边距；要让文字与形状/线条边缘对齐时，把文本框 `margin` 设为 0 或补偿偏移。
